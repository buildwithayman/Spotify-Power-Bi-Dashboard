# Spotify-Power-Bi-Dashboard

🎧 Spotify Music Analytics Dashboard | Power BI Project

Excited to share my latest Spotify Music Analytics Dashboard built using Power BI, where I analyzed global music data to uncover trends in songs, artists, popularity, and album performance.

This project focuses on transforming raw music data into interactive insights using advanced data modeling and visualization techniques.

🔧 Tools & Technologies Used
• Microsoft Power BI
• Power Query (Data Cleaning & Transformation)
• Data Modeling
• DAX Measures
• Interactive Visualizations & Navigation Buttons

🗂 Dashboard Structure

The dashboard consists of 4 interactive pages connected through navigator buttons:

1️⃣ Home Page
A landing page designed with Spotify-style UI to navigate across different analytical sections.

2️⃣ Overview Page
Provides a high-level summary of the dataset including key performance indicators and trends.

3️⃣ Artists Page
Analyzes artist performance and popularity metrics across the dataset.

4️⃣ Songs Page
Explores song-level insights including popularity, release dates, and album details.

📊 Key KPIs & Metrics

• 28K Total Songs analyzed
• 342 Distinct Artists
• 3.28 Avg Duration (minutes)
• 90 Avg Popularity Score

📈 Key Visualizations

• Distinct Songs by Album Type
• Explicit vs Non-Explicit Songs distribution
• Distinct Songs by Year
• Average Popularity by Album Type
• Average Popularity Trend by Quarter
• Distinct Songs by Quarter
• Songs by Artist ranking
• Popularity by Artist
• Top Songs by Popularity
• Position #1 Hits by Artist
• Detailed song-level table analysis with release date, popularity, and duration metrics.

💡 Key Insights

• Albums contribute the largest share of songs compared to singles and compilations.
• Popularity trends fluctuate across quarters indicating changing listener preferences.
• A few artists dominate the charts with multiple top-ranked songs.
• Explicit songs represent a significant portion of popular tracks.

✨ This project demonstrates how Power BI can be used to analyze music industry data and convert it into meaningful insights through interactive dashboards.
